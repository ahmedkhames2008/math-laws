Math Rules Summary

Unit 7: Differentiation

v(h) = [f(x + h) - f(x)]
A(h) = [f(x + h) - f(x)] / h
Rate Of Change = lim(h→0) [f(x + h) - f(x)] / h
d/dx [c] = 0
d/dx [xⁿ] = n * xⁿ⁻¹
d/dx [f(x) ± g(x)] = f'(x) ± g'(x)
d/dx [f(x) * g(x)] = f(x) * g'(x) + f'(x) * g(x)
d/dx [f(x) / g(x)] = (f'(x) * g(x) - f(x) * g'(x)) / g(x)²
If y = f(g(x)), then dy/dx = f'(g(x)) * g'(x)
If y = [f(x)]ⁿ, then dy/dx = n[f(x)]ⁿ⁻¹ * f'(x)
If x = f(t), y = g(t), then dy/dx = (dy/dt) / (dx/dt)
d/dx [sin(x)] = cos(x)
d/dx [cos(x)] = -sin(x)
d/dx [tan(x)] = sec²(x)
d/dx [e^x] = e^x

Unit 8: Geometry

Similarity: Corresponding angles equal, sides proportional
Dot Product: A · B = x₁x₂ + y₁y₂ OR |A||B|cos(θ)n̂
Cross Product: A × B = (x₁y₂ - y₁x₂)k OR |A||B|sin(θ)n̂
Vector A = xi + yj + zk
||A|| in 2D = √(x² + y²) || in 3D = √(x² + y² + z²)
Vector Line: r = A + t·d
Parametric Line: x = x₁ + ta, y = y₁ + tb, z = z₁ + tc
Cartesian Line: (x - x₁)/a = (y - y₁)/b = (z - z₁)/c
Circle (Standard): (x - x₁)² + (y - y₁)² = r²
Circle (General): x² + y² + 2mx + 2ny + c = 0
Plane (Vector): n·r = n·a
Plane (Standard): ax + by + cz + d = 0
Sphere (Standard): (x - l)² + (y - k)² + (z - n)² = r²
Sphere (General): x² + y² + z² + 2lx + 2ky + 2nz + d = 0
